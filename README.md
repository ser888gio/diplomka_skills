# Diplomka Skills

Tento projekt obsahuje asistenta (skill) pro GitHub Copilot, který pomáhá studentům s psaním diplomových prací.

## O projektu

Hlavním cílem tohoto nástroje je poskytnout studentům expertní vedení při strukturování, psaní a citování jejich závěrečných prací v souladu s aktuálními metodickými pokyny.

## Obsah

- `diplomova-prace/SKILL.md`: Hlavní definiční soubor asistentových instrukcí, pravidel a znalostní báze.
- `diplomova-prace/assets/`: Složka pro doprovodné materiály, jako jsou oficiální šablony prací.

## Hlavní funkce asistentů

Asistent poskytuje rady v následujících oblastech:
- **Struktura kapitol:** Dodržení závazného pořadí od Úvodu až po Závěr.
- **Formátování:** Pravidla pro písmo, řádkování, okraje a rozsah (60-80 stran).
- **Citování:** Správné použití normy ČSN ISO 690 a vyhledávání v akademických databázích (Web of Science, Scopus).
- **Akademické psaní:** Dodržování 3. osoby trpného rodu a vyhýbání se plagiátorství.
- **Kontrolní seznam:** Finální revize před odevzdáním práce.

## Jak používat

Pokud máte tento repozitář otevřený ve VS Code s aktivním GitHub Copilotem, asistent se automaticky aktivuje pro dotazy týkající se psaní diplomové práce.
